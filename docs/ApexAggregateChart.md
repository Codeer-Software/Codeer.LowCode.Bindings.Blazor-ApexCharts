# 集計チャート (ApexAggregateChartFieldDesign / ApexAggregateHBarChartFieldDesign / ApexAggregateRadialChartFieldDesign)

元モジュールの行をカテゴリの項目でまとめ、DB 側で集計してグラフにするフィールドです。
「月別の売上」「状態別の件数」「担当ごとの合計の上位 10」のような、行をまとめて数えるグラフに使います。

- 集計は Codeer.LowCode.Blazor の集計 API で行います。行を全部ブラウザに読み込まないので、行数が多くても重くなりません
- 権限は一覧と同じです (読めない行は数えない・読めない項目は使えない)
- 集計用の QueryField モジュールを用意する必要はありません

行をそのまま点にするグラフ (散布図・1 行 = 1 点の推移) は従来の [ApexChart](ApexChart.md) / [ApexHBarChart](ApexHBarChart.md) / [ApexRadialChart](ApexRadialChart.md) を使います。

[← README に戻る](../README.md)

## 3 つのフィールド

| フィールド | Designer 上の名前 | 系列 | 系列を分ける項目 |
| --- | --- | --- | --- |
| `ApexAggregateChartFieldDesign` | 集計チャート | 複数。系列ごとに集計方法・種類 (棒 / 折れ線 / 面 / ヒートマップ)・色 | あり |
| `ApexAggregateHBarChartFieldDesign` | 集計横棒チャート | 複数 (棒に固定) | あり |
| `ApexAggregateRadialChartFieldDesign` | 集計円チャート | 1 つ (円 / ドーナツ / ポーラー) | なし |

## 共通プロパティ

| プロパティ | 表示名 | 既定値 | 説明 |
| --- | --- | --- | --- |
| `SearchCondition` | 検索条件 | (空) | 元モジュールと条件。並び・件数上限は使いません。空にするとスクリプトの `Show` 専用になります |
| `DisplayName` | 表示名 | (空) | グラフのタイトル |
| `CategoryField` | カテゴリフィールド | (空) | カテゴリにする項目。文字・数値・日付・日時・選択・リンク・真偽。選択とリンクは表示名で出ます |
| `CategoryDateUnit` | まとめる単位 | まとめない | 日付・日時のカテゴリを 年 / 四半期 / 月 / 週 (月曜始まり) / 日 / 時 でまとめます |
| `FiscalYearStartMonth` | 年度の開始月 | `1` | 年・四半期でまとめるときの年度の開始月 (4 なら 4 月〜翌 3 月) |
| `CategoryOrder` | カテゴリの並び | 項目の順 | 項目の順 / 値の大きい順 / 値の小さい順 (先頭の系列の値で比べる) |
| `CategoryLimit` | カテゴリの上限 | `0` (なし) | 並びの先頭から N 件 |
| `ShowLegend` | 凡例を表示 | `true` | |
| `CanCustomize` | 利用者が集計を変更できる | `false` | 利用者が集計を自分用に変えられます (後述) |

カテゴリの見出しは まとめる単位 に合わせて `2026` / `2026 Q2` / `2026-04` / `2026-04-06` / `2026-04-06 09:00` になります (年度のときは年度の開始年)。空値は「(空白)」です。

## 集計チャート・集計横棒チャートのプロパティ

| プロパティ | 表示名 | 既定値 | 説明 |
| --- | --- | --- | --- |
| `Series` | 系列 | (空) | 系列の一覧。専用のダイアログで 集計方法 (合計 / 件数 / 平均 / 最小 / 最大)・項目 (数値)・見出し・種類・色 を編集します |
| `SeriesGroupField` | 系列を分ける項目 | (空) | 指定すると、その値ごとに系列を作ります (例: 状態ごとに色分けした棒) |
| `SeriesFractionDigits` | 系列の小数桁数 | `2` | 値の軸ラベルの小数桁 |
| `ShowXAxisGrid` / `ShowYAxisGrid` | X軸 / Y軸グリッドを表示 | `false` / `true` | 集計チャートだけ |

- 見出しが空なら「項目の表示名 集計方法」(件数は「件数」) を凡例に出します
- 系列を分けたときは、系列 = 値 × 分けた値 です。色は既定の色を順に使い、凡例は分けた値になります (値が複数なら「分けた値 / 値の見出し」)
- 集計横棒チャートでは種類は選べません (棒で描きます)

## 集計円チャートのプロパティ

| プロパティ | 表示名 | 既定値 | 説明 |
| --- | --- | --- | --- |
| `SeriesType` | 系列タイプ | 円 | 円 / ドーナツ / ポーラー |
| `SeriesFunction` | 集計方法 | 件数 | 合計 / 件数 / 平均 / 最小 / 最大 |
| `SeriesField` | 系列フィールド | (空) | 集計する数値の項目 (件数のときは不要) |

## 動き

- 画面に置くと、表示したときに集計して描きます。UTC で保存した日時は見ている人 (ブラウザ) の時差で区切ります
- 検索フィールドの「結果を表示するフィールド」に指定できます。検索条件は設計の条件と AND で効きます。画面に検索フィールドを置いたときは、検索フィールドの初回検索で集計します (初期表示で 2 回集計しません)
- 検索条件が画面の項目を参照していれば、その項目が変わったときに集計し直します
- カテゴリの上限は カテゴリ に掛かり、分けた系列は全部出ます
- 棒や点にマウスを乗せると集計値をツールチップで出します (従来のチャートと違い既定で有効。ツールバーは出しません)
- 集計に失敗したときは、グラフの位置にエラーの文言を出します。アプリ (ホスト) が集計 API に対応していない場合もここに出ます (1.3.39 より前のテンプレートで作ったアプリは [集計 API の結線](https://github.com/Codeer-Software/Codeer.LowCode.Blazor.Manual/blob/main/JP/user_code/aggregate_api.md) を行ってください)

## 利用者のカスタマイズ

`CanCustomize` をオンにすると、グラフの右上に「集計のカスタマイズ」ボタンが出て、利用者が自分用の集計に変えられます (スクリプトの `ShowCustomDialog()` でも開けます)。ボタンは集計がエラーのときも出るので、変えた設定がエラーになっても直すか「設計に戻す」で戻せます。クロス集計・ListField のカラムカスタマイズと同じ考え方で、変えた内容はその利用者のブラウザにだけ保存されます。全員に同じ集計を見せたいときは設計で設定します。

- 変えられるもの: カテゴリの項目 (リンク先の項目も選べます)・まとめる単位・年度の開始月・系列を分ける項目・系列 (集計方法・項目・見出し・種類)・カテゴリの並び・カテゴリの上限 (デザイナのプロパティと同じ項目)
- 集計横棒チャートの系列は棒のまま、集計円チャートは値 1 つで種類は 円 / ドーナツ / ポーラー から選びます (系列を分ける項目はありません)
- 変えられないもの: 元モジュール、検索条件、タイトル・凡例・軸などの表示の設定、系列の色
- 「設計に戻す」で保存した内容を消して設計どおりに戻します。設計と同じ内容にしたときも保存は消えます
- 保存先はブラウザの localStorage で、キーは「モジュール名.フィールド名」です。同じブラウザを使う人の間では共有されます
- 設計が変わって保存内容に無い項目が含まれるようになったら、保存内容は使わず設計どおりに表示します
- OK のときに、系列が無い・数値でない項目の合計・ヒートマップと他の種類の混在 などの不整合があればエラーを出し、ダイアログを開き直します
- 読めない項目を選ぶとサーバーが集計を拒否し、グラフの位置にエラーが出ます。カスタマイズを開き直すか「設計に戻す」で戻せます
- スクリプトの `Show` で集計を渡しているグラフでは、保存した内容を使わず、カスタマイズも開きません

## 注意事項

- 集計できるのはテーブルを持つモジュールだけです (QueryField で定義したモジュールは使えません)
- SQLite では日付の列を DATE / DATETIME で宣言してください (TEXT で宣言した列は、まとめる単位 (年・四半期・月など) でまとめられません)

## デザインチェック

| 指摘コード | 内容 |
| --- | --- |
| `ApexAggregateChartFieldDesignBase:1` | カテゴリの項目が未設定 |
| `ApexAggregateChartFieldDesignBase:2` | 日付・日時でない項目に まとめる単位 を指定 |
| `ApexAggregateChartFieldDesignBase:3` | 数値でない項目を集計 (件数は項目不要) |
| `ApexAggregateChartFieldDesignBase:4` | ヒートマップの系列と他の種類の混在 |
| `ApexAggregateChartFieldDesignBase:5` | 系列が無い |
| `ApexAggregateChartFieldDesignBase:6` | 元モジュールがテーブルを持たない (QueryField で定義したモジュール・テーブルの無いモジュール) |

項目が存在するかどうかは本体のチェックで確認します。元モジュールが空のときはスクリプト専用として指摘しません。
